# HooBank

A modern fintech landing page built from a Figma design and implemented as a responsive Next.js frontend.

The project focuses on accurate UI implementation, reusable components, responsive behavior, and a polished fintech visual style.

## Live Demo

https://hoo-bank-ha.vercel.app/

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS

## Highlights

- Figma-to-code implementation
- Responsive landing page
- Reusable React components
- Responsive navigation
- Hero and feature sections
- Service and statistics sections
- Responsive layouts across screen sizes
- Clean and maintainable component structure

## Development Focus

I focused on translating the original design into a production-ready frontend while preserving:

- Visual hierarchy
- Spacing and layout
- Typography
- Responsive behavior
- Component reusability
- Overall design consistency
